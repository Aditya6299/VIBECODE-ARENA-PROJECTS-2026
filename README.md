# 🚀 Vibe Code Arena | TechTrix'26

Welcome to **Vibe Code Arena**, a project-building challenge at **TechTrix'26, ITS Engineering College**.

Choose one of the problem statements below, build a functional solution from scratch, and showcase your innovation through a live demo.

## 📌 Problem Statements

### PS-01: Smart System for Detecting Phishing and Cyber Fraud
Develop a cybersecurity tool that analyses suspicious emails, SMS messages, URLs, and screenshots to identify potential phishing and fraud. Include explainable risk assessments, safety recommendations, cyber awareness resources, incident reporting, and a basic admin dashboard.

### PS-02: Unified Government Scheme and Housing Assistance Finder
Build **SchemeSaathi**, a portal that matches citizens with relevant government welfare schemes based on their location, income, occupation, age, and family details. Display eligibility criteria, benefits, required documents, and official application links.

### PS-03: Morphed Image Abuse Reporting Assistant
Develop **NariSuraksha AI**, a privacy-focused platform that helps users document online image abuse and impersonation. Include evidence checklists, incident timelines, cybercrime reporting guidance, content-removal resources, and AI-assisted guidance in Hindi or English.

### PS-04: Cybersecurity Verification and Awareness Tool
Create a tool that detects potential phishing and cyber fraud in messages, emails, URLs, and screenshots. Provide risk assessments, safety recommendations, educational resources, incident reporting, and an administrative dashboard.

### PS-05: Smart Counterfeit Product Detection Platform
Build **TrustMark**, a platform that checks product identifiers, QR codes, barcodes, and packaging images against sample product records. Flag suspicious products, explain authenticity risks, and support counterfeit reporting and verification history.

### PS-06: AI-Powered Smart Queue Management Platform
Develop **QueueSmart AI**, a system for digital queue registration, token generation, waiting-time estimation, and live queue monitoring. Include appointment slots, configurable priorities, simulated notifications, and an admin dashboard.

## 🛠️ Development Guidelines

- Build a **functional prototype** that addresses your selected problem statement.
- Use suitable technologies and clearly document the technology stack.
- Use sample or simulated data wherever appropriate.
- Follow relevant privacy, security, and safety requirements.
- Clearly explain implemented features and any limitations.

## 📤 Submission Guidelines

Your project submission should include:

- **Project name and problem statement ID**
- **Project description and key features**
- **Source code and necessary project files**
- **Technology stack and setup instructions**
- **Screenshots or demo link**, if available

Upload your project to this repository using the submission process specified by the organisers. **Do not upload API keys, passwords, or confidential information.**

## 📋 Rules & Judging Guidelines

- **Time-Boxed Demo:** 3 minutes for the demo, followed by 1–2 minutes of Q&A.
- **Live Demo Mandatory:** Demonstrate a working product; prioritise functionality over slides.
- **Fresh Build Only:** Everything must be built within the event's **90-minute window**. Pre-built or old projects may lead to mark deductions or disqualification.
- **Fair Evaluation:** All judges will use the same scoring rubric. The average score will be used as the final score.
- **Optional Checkpoint:** A check-in at approximately 45 minutes may help teams stay on track.
